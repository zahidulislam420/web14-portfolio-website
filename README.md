# Portfolio Website:

A modern and responsive personal portfolio website built with **HTML5 & CSS3**.  
This project highlights my skills, experience, and creative works in a clean and professional layout.
Website live link: https://zahidul-dev.github.io/web14-portfolio-website/

## Features
- **Responsive Navbar** with logo and navigation links
- **Hero Section** introducing myself with call-to-action buttons
- **About Section** with personal details (name, email, DOB, phone)
- **What I Do Section** showcasing technical skills and technologies
- **Gallery Section** to display amazing works/projects
- **Footer Section** with social media icons and contact form

## Technologies Used
- **HTML5** → Semantic structure
- **CSS3** → Styling, layout, responsiveness
- **Flexbox & CSS Grid** → Layout management
- **Custom Buttons & Forms** → Interactive elements
- **FontAwesome / Custom Icons** → Visual enhancements

---

## CSS Highlights
- **Global Reset** → `* { margin:0; padding:0; }`
- **Reusable Buttons** → `.common-btn` & `.outline-btn`
- **Flexbox Navbar** → Clean alignment of logo & links
- **Hero Section** → Two-column layout with text + image
- **About Section** → Styled info boxes
- **What I Do Section** → Skill cards with borders & hover effects
- **Gallery Section** → Creative grid layout using `grid-template-areas`
- **Footer** → Two-column layout with social icons & styled contact form
